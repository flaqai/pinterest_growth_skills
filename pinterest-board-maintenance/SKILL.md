# Pinterest 长期画板维护

围绕指定产品，紧跟目标市场的实时热点和用户兴趣，做成有独立看点、符合账号风格的原创 Pin，按主题新建或续更画板。作品与目标产品页保持关联。外链建设和真实读者访问同等重要。

## 启动任务

从对话和项目记录确认品牌或账号、目标产品页、本轮阶段和用户已定的范围。按当前项目的操作说明核对已有画板清单和维护记录。影响当前步骤的缺项一次问齐，未定的地区、语言和风格可在调研后建议。参考数量、画法、图片比例和交付形式按任务用途决定。

新选题先看目标市场的当期热点和用户正在关注什么，再判断怎样结合账号风格与产品，并用画板清单查重和确定归属。默认制作静态图片 Pin，用户明确要求时才制作视频 Pin。按用户明确给出的题材、画板或条数办。只查市场、只交方案或只审查内容时，交对应结果。已确认的方案直接进入制作。局部修改沿用相关依据，按用户给定的范围修改和复核。已授权发布时，从核对账号、画板和最终稿开始。

可复制下面的模板，填入这次已知的信息。

```text
$pinterest-board-maintenance
品牌或账号【填写名称】
目标产品页【填写网址】
本次希望做到【查趋势／给画板和 Pin 方案／制作图文／验收或修改／发布】
其他已定要求【可选，如地区、语言、画板、条数或风格】
```

## 调研与选题

用浏览器调研时尽量复用同一张标签页，确需对照时少量加开。同批共用有效的依据，只补会影响选题、排序或画法的缺口。

- **四类依据。** 开放找题查目标地区最新可取得的无筛选全类目明细。用 **Top monthly trends** 看月度搜索规模，用 **Growing trends** 找近期升温的话题。再看 **Trends in the spotlight**（收藏走势）、相关 **Moments** 的节点详情（活动时机）和 **Pinterest 社区**的具体案例（创作者或平台人员的实际做法）。用户限定题材时按其范围查，未指定市场时选有依据的主要用户地区。来源取不到或不适用时说明原因。
- **数据口径。** 优先用原生数据，必要时在获授权的工作浏览器里只读核验。用同地区、同时间窗和同筛选口径的周月变化或曲线判断升温、见顶和回落。区分搜索、收藏、预测和单帖互动。具体转折日期用带日期的数据支持，细分词缺曲线时可引用上一级走势并注明缺口。记录实际使用的榜别、地区、查阅日、截止日、关键词、筛选条件和原始链接。链接无法复现引用的数值时，附可取得的截图或导出。实际搜索量和转化需有独立证据。
- **实际作品参考。** 看 Pinterest 或小红书的实际作品，判断用户对什么题材、画风、氛围或做法感兴趣，再提取取景、光影、材质和缩图看点。可用一个主参考或多条相互印证，按需要对照不同作者及同板旧作。美甲优先看小红书等平台的爆款实拍，借鉴自然手势、取景和光线。用小红书样本时，在目标市场的 Pinterest 快查同类作品或关键词。把与题材有关的官方指南和创作者实作经验用到画面。 [Pinterest 创作指南](https://create.pinterest.com/en-gb/fundamentals/)
- **找全当期热点。** 把月榜靠前、多词上榜、近期明显升温和临近活动带动的话题放在一起比较，覆盖不同类目。按用户感兴趣的主题归组，近义词合并，关注点或时机不同的分别列。逐组考虑怎样把热点做成用户愿意点开或收藏的图，再结合账号风格和产品判断拟做、试做或暂缓。列代表词和近期走势，有月榜数据时列同口径的排名和指数。
- **丰富题材，列齐后再定数量和画板。** 把有热点或用户兴趣依据、时机合适且能结合品牌风格和产品的方向都展开为具体 Pin。高频周方案从不同兴趣主题扩充。同一热点可用不同场景、画风或做法展开，每条都有独立看点。构思重复时合并，优先从其他有依据的方向补足。列齐后再统计数量、排先后。值得探索的同案列为试做，写清待验证的问题。已有画板主题相符就续更，适合长期做且没有合适旧板的主题纳入本轮新板方案。开放选题提交前对照原始榜单、收藏焦点和节日节点，逐组核对可做方向是否都有具体 Pin。暂缓的写明实际原因，重复的写明合并到哪个方向。只有续更时，再查榜上有没有适合新建的方向。

## 开工方案与确认

**开工证据检查。** 完整方案写清四类依据各查到了什么、来源和如何用于本轮。开放选题须读完目标地区无筛选月榜和上升榜的明细，并完成逐组查漏。每个拟做方向对应趋势或兴趣依据和实际看过的相关作品，相关 Pin 可共用。用细分词走势支持选题时核对对应曲线。无独立数据时说明借用哪一级的趋势，以及细分题材的热度还没核实。先补齐关键依据，再提交完整方案并请用户确认开工。确实取不到时只交阶段结果和具体缺口，用户明确同意按阶段方案制作时依其要求继续。

完整方案在同一份清单中列出各题材方向、依据、取舍、新建或续更的画板、具体 Pin 和总数。注明先做什么和本轮做到哪一步。按周发布时，在同一份方案写明七天拟发总数、每天的条数和题材搭配。分批制作或排期时，仍列出本轮已发现的可做方向。另发确认摘要时保留影响决定的依据。新板写清用途、名称、可直接用的简介、封面方向和共同画风，续更说明如何接上旧作。画风用用户指定的风格、已核实的品牌作品或官方产品示例作依据，新尝试标为本轮提议。

在方案中说清每条 Pin 抓住哪种当期兴趣、缩图有什么看点、怎样体现品牌，以及和目标产品页的关联。说明实际借鉴的案例或社区做法，相关链接可按主题共用。提到产品操作时核对是否支持。承诺成品时写清规格和获取方式。相近构思和可比旧作并排看，按看点拉开构图、光色或设计。

只按参考作品试做时，给原帖或精选卡及拟做版本，交代归板和用途。美甲等需要实拍底图的题材，由模型主动搜索并收集合用素材。可从品牌已有素材、许可明确的图库和获准使用的作者原图找。第三方原图用于编辑、生成或发布时，核对许可覆盖实际用途并注明来源。找不到合用底图时，继续查同用途素材或调整构思。

用户确认方案后开始制图、写文案或交办制作。按确认的用途和可见要求调整画法，超出确认范围的变动只确认涉及的部分。

## 制作、验收与交付

1. **制作主图。** 按确认的用途和画面看点选构图、比例、光色和工具，图上文字服务作品。涉及人体局部细节时优先用已核对的实拍底图。按需局部修改，保留自然结构、比例、纹理和原有光影。美甲可只改甲色或纹样，保留手型和甲形。
2. **准备文案。** 画板名和简介说清用途，标题自然使用贴题的搜法。描述先介绍成图的看点和创意，自然带入相关搜索词。按需加贴题的话题标签（hashtag），产品用法能补充作品时再写。名称、简介、标题和描述默认省略品牌名。对照成图定稿，替代文字写可见内容。提示词按需要提供，有变体时说清改了什么和可见差别。标明样图实际来源，功能、费用、生成结果和商用说法需有证据。产品网址只填 Pin 的 Link 字段，商品标签按实际适用性处理。
3. **模型批量验收。** 按画板或题材分组检查所有实际图片和最终文案。并排看相近作品和可比旧作，判断各条是否有独立看点、值得点开或收藏，必要时放大检查细节。实拍改图对照原图看保真。核对图文、目标链接、画板和相关发布字段。文案提到产品操作时，核实读者在目标页确实能试。发现问题直接修并复查，或换用方案内已通过验收的内容。
4. **交最终稿。** 交可取用的图文及所需发布信息。周批次从同一份通过验收的定稿生成七天 CSV，简要说明可排期的条数和影响发布的缺口。需要用户决定时只展示相关图文和具体取舍。用户想看成品时按需展示。已有发布授权的合格条目按计划进入排期。

对照试验按问题决定共用条件。独立创作用新图和新文案，比较文案可用同图。成品验收、受众表现和产品生图能力分别判断。

## 排期、发布核验与持续维护

- **默认每周高频排期。** 一次集中制作一周的 Pin，验收后生成一份覆盖连续七天的 CSV。按目标受众时区每天安排多条，分时段穿插不同题材和画板。相近内容尽量分到不同日期，时效强的选题优先。以 96 条为例，5 天每天 14 条，2 天每天 13 条。实际条数按当期可做题材和通过验收的作品定。
- **准备导入表。** 按 [Pinterest 官方批量导入说明](https://help.pinterest.com/en/business/article/bulk-upload-video-pins) 从最终稿生成 CSV，每条一行，含标题、公开媒体直链、准确画板名、描述、目标链接和 `Publish date`（发布时间）。同一产品页的不同原创 Pin，用固定 Pin 编号作 `utm_content`（点击来源标记），保留原有业务参数并核对仍到达指定页面。重试沿用同一标记，检查表内链接是否重复。默认用图片直链，用户要求的视频按模板填缩略图。发布时间换算为协调世界时（UTC），每次上传前检查空值和过期时间，将未入队的过期条目重新排到未来。日期留空会立即发布。导入会为不存在的名称创建画板或分区，先核对是否属于本轮范围。替代文字、原生主题标签、画板简介和封面按平台支持的方式补齐。
- **导入并核对排期。** 核对当次授权、实际账号、画板和最终稿，在 Pinterest 商业账号「设置 → 导入内容」导入整周，由 Pinterest 到点发布。对照七天计划核对实际排期条数、时间和画板，记录已排期、待处理、失败和已发布。部分成功或结果不明时，按处理回执逐条查排期和已发布列表，失败清单以外的条目也要核对。只将确认失败且未入队、未发布的条目放进重试 CSV。批量入口不可用、仍报链接重复，或必要字段无法保留时，使用原生逐条排期。有正式 Pin 就核验公开链接。
- **读者页核验。** 逐条对照最终稿查主图、标题、描述、替代文字、画板归属和外链落点。替代文字未展示时可查公开页数据。承诺有成品时核对获取路径和文件规格，新增或修改画板时核对简介和封面。写清一致、差异、字段确认为空或待核验，修复后只复查受影响项。
- **记录与续更。** 交公开链接和读者侧结论，在现有交付记录、发布稿页和画板清单更新归属、链接、日期、证据和差异。区分候选、样稿、用户报告发布、账号内确认、人工验收和公开页核验。有数据后按相同发布时长比较展示量、收藏数、外链点击数和比率，结合最新趋势和用户对各题材的反应决定是否续更。发布语言、实际受众地区和可归因的转化分别记录，小样本作线索。

恢复已停止的操作需有明确指示。

维护技能时，按用户明确的长期要求更新通用流程。单次试验的数量、比例、工具和协作设置放在对应案例里。
